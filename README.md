# LG Sales Coach

Dưới đây là prompt hoàn chỉnh để copy vào Lovable, mình đã gom toàn bộ các yêu cầu bạn đã đưa trước đó: mục tiêu training Sales, chia từng model, ảnh đúng từ LG Vietnam, ATA, tư vấn, giá, quà tặng và thiết kế theo kiểu dễ sử dụng khi bán hàng.

Create a professional and user-friendly LG Subscribe Sales Training Landing Page for LG Sales/PCs.

The main purpose of this website is to help Sales staff learn the products, understand LG Subscribe benefits, consult customers and close sales directly.

1. MAIN OBJECTIVE

This is NOT just a product catalog.

It should work as a Sales Training + Customer Consultation Tool.

Sales staff should be able to quickly:

Learn product information.

Understand key product advantages / ATA.

Understand customer benefits.

Learn how to consult customers.

Know which product to recommend based on customer needs.

Handle common customer objections.

Check the exact subscription price.

Check Care Service and Extended Warranty (EW).

Check the current promotion and gift.

Use the information directly when speaking with customers.

2. PRODUCT CATEGORIES

Create separate sections/pages for each product category.

For example:

Refrigerator (REF)

Washing Machine (WM)

Air Conditioner (RAC)

Air Care

TV

Styler

Other LG Subscribe products

The exact product categories and models must follow the product list I provide.

3. IMPORTANT: SEPARATE EVERY MODEL

Do NOT combine several models into one product page.

The structure must be:

Product Category → Model → Product Details

Example:

REF

Model A

Model B

Model C

WM

Model A

Model B

Model C

RAC

Model A

Model B

Model C

Each individual model must have its own product card and detail page.

4. PRODUCT IMAGE – VERY IMPORTANT

Use ONLY official LG product images from:

LG Vietnam: https://www.lg.com/vn/

Do NOT use:

AI-generated images

Stock images

Placeholder images

Images from other websites

Images of similar LG models

Image Matching Rule

The model code in my provided product list is the source of truth.

For every model:

Model Code → Search LG Vietnam → Find exact model → Use official LG image

The image must match the exact model code.

If LG Vietnam has several images, prioritize:

Main product image

Front / side product image

Lifestyle / in-use image

If an exact model image cannot be found:

Do NOT replace it with another model.

Show:

“Official image not available”

The product image must always match the product model.

5. PRODUCT DETAIL PAGE

Each individual model must contain the following information:

A. Product Information

Product name

Exact model code

Product category

Product type

Capacity / size

Main specifications

B. Product Image

Use the exact official LG Vietnam image for the model.

C. Key Features

Show the most important product features in a simple and visual way.

Use icons / short descriptions instead of long paragraphs.

D. ATA – KEY SELLING POINTS

Clearly show:

Why should the customer choose this product?

Include:

Main product advantages

Key technical advantages

Customer benefits

Advantages compared with conventional products / competitors where applicable

3–5 key selling points that Sales should remember

6. CUSTOMER CONSULTATION TRAINING

For every model, provide a practical consultation guide.

Include:

Customer Needs

Who is this product suitable for?

What customer problem does it solve?

What type of customer should Sales recommend this model to?

Questions to Ask

Provide recommended questions for Sales to ask customers.

Example:

What is your current product?

What problem are you facing?

How many people will use the product?

What is your preferred budget?

What features are most important to you?

Recommended Sales Message

Provide a short and natural script:

“If the customer says X → recommend Y because…”

Objection Handling

Include common customer objections such as:

“The price is expensive.”

“Why should I subscribe instead of buying directly?”

“I don’t need Care Service.”

“I can buy a cheaper product.”

“Why do I need Extended Warranty?”

Provide simple recommended responses for Sales.

Closing

Provide 2–3 simple closing questions that Sales can use.

7. LG SUBSCRIBE VALUE PROPOSITION

Clearly explain why customers should choose LG Subscribe instead of purchasing the product directly.

Show the key benefits:

Flexible payment

Care Service

Extended Warranty

Convenience

Product maintenance

Long-term customer support

Other benefits applicable to the product

Use simple visual cards.

Example:

BUY
Product only

vs.

LG SUBSCRIBE
Product + Care Service + EW + other benefits

8. PRICE INFORMATION

For every individual model, clearly show:

Product price

Monthly subscription price

Annual price where applicable

Subscription period

Care Service price

Extended Warranty price

Total applicable price

Price information must be linked to the exact model.

Do NOT mix prices between models.

9. PROMOTION & GIFT

For every model, clearly show:

Current promotion

Gift

Gift value

Promotion period

Eligibility / conditions if applicable

Make the gift information visually attractive.

Example:

SPECIAL OFFER

🎁 Free Gift
[Gift Name]

Gift Value: XXX VND

10. PRODUCT COMPARISON

Where multiple models exist in the same category, provide a simple comparison function.

Allow Sales to compare:

Model

Key features

Capacity

ATA

Subscription price

Care Service

EW

Promotion

Gift

The comparison should help Sales quickly recommend the most suitable model.

11. SALES QUICK GUIDE

Create a section called:

“Quick Sales Guide”

For each product, show only the most important information:

Remember these 5 things:

Product

Main ATA

Customer benefit

Subscription price

Promotion / Gift

This section should be usable while Sales is talking directly to a customer.

12. SEARCH & FILTER

Add a search function so Sales can quickly find a model by:

Model code

Product name

Product category

Add filters by:

Product category

Price range

Product type

13. HOMEPAGE

The homepage should be simple and focused.

Header:

LG SUBSCRIBE SALES TRAINING CENTER

Subtitle:

Learn → Consult → Recommend → Close

Main navigation:

Products | Sales Training | Price & Promotion | Product Comparison

Show product categories as visual cards.

Example:

REF | WM | RAC | AIR CARE | TV | STYLER

14. DESIGN

Use a modern LG-style premium design.

Requirements:

Clean

Professional

Premium

Easy to understand

Mobile responsive

Suitable for iPhone and tablet

Large product images

Clear CTA buttons

Use cards and icons

Avoid excessive text

Use clear visual hierarchy

Important information should be visually highlighted:

ATA | PRICE | SUBSCRIBE BENEFITS | PROMOTION | GIFT

15. USER EXPERIENCE

The website must be extremely easy for Sales staff to use.

A Sales person should be able to:

Open website → Select category → Select model → Understand product → Check ATA → Learn how to consult → Check price → Show promotion → Close sale

Keep navigation simple and fast.

16. DATA ACCURACY – VERY IMPORTANT

The model code is the single source of truth.

These items must always match the same model:

Model Code ↓ Product Image ↓ Product Information ↓ Specifications ↓ Features ↓ ATA ↓ Subscription Price ↓ Care Service ↓ EW ↓ Promotion ↓ Gift

Never mix information between different models.

If information is missing, clearly mark:

“Information not available yet.”

Do not invent product information, pricing, promotion or specifications.

17. FINAL REQUIREMENT

Please restructure the entire landing page so that it is model-based, not only category-based.

Every model should have a complete mini training page containing:

IMAGE → PRODUCT INFORMATION → FEATURES → ATA → CUSTOMER BENEFITS → CONSULTATION SKILLS → OBJECTION HANDLING → SUBSCRIPTION BENEFITS → PRICE → CARE SERVICE → EW → PROMOTION → GIFT → SALES QUICK GUIDE

The final website should feel like a digital LG Subscribe Sales Training Handbook + real-time Customer Consultation Tool, rather than a normal product website.
